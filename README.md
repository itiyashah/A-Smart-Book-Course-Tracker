# A-Smart-Book-Course-Tracker
An automated resource tracker using Tally forms and Notion databases.

## 🚀 How it Works
1. **Intake:** Submit a learning resource via a public Tally Form.
2. **Pipeline:** Tally automatically maps form fields to the Notion API.
3. **Database:** Notion captures the variables into a structured database in real time.

## 🔗 Live Links
* **Live Tally Form:** https://tally.so/r/2EY6yM

# Configuration & Setup Guide

### 1. Notion Setup
* Created a table database named `My Learning Hub`.
* Configured the 6 primary properties listed in `schema.md`.

### 2. Tally Integration Settings
* Navigated to **Integrations** -> **Notion** inside the Tally editor.
* Authorized the specific Notion workspace.
* Mapped fields exactly as documented in the schema file.
* Status: **Active** 🟢
